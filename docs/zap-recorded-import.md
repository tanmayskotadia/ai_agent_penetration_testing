# OWASP ZAP recorded Alerts import (T25)

The product exposes an offline import for a user-supplied ZAP 2.x Alerts JSON document (`{"alerts": [...]}`). It does not launch ZAP, call ZAP's API, follow links, make HTTP requests, or start either passive or active scanning. ZAP's API and Automation Framework can control scans; those control operations are outside this importer. A future runner must independently bind an approved target context, exclusions, authentication material, scan-impact profile, single-use approval, timeout, cancellation and egress policy before any request is sent.

The importer validates bounded JSON in the isolated parser child, rejects duplicate keys and unsupported shapes, records scanner alert/plugin references, source risk/confidence labels, JSON pointers, HTTP method and endpoint path, and checks each captured URL against the user-declared assessment scope. Exclusions quarantine the full import. The original file remains encrypted evidence with a source hash. Query strings and request/response bodies are not copied into normalized output. Imported alerts become `observed-evidence` observations in `suspected` state; no vulnerability concept, CVE, confirmed finding, calibrated probability or exploitability conclusion is generated.

The parser currently recognizes the ZAP 2.x Alerts JSON shape and common alert instance fields. It is a candidate import normalizer, not a verified product integration: hand-authored samples validate software behavior only. Production acceptance still requires review of genuine outputs from a supported ZAP version, source/redaction review, supported authentication/session coverage evidence, and an organizer-authorized lab demonstration. Until then the seven-tool capability registry remains `planned` and the verified integration count remains zero.

For a format reference, see the [ZAP API documentation](https://www.zaproxy.org/docs/api/) and [Automation Framework documentation](https://www.zaproxy.org/docs/desktop/addons/automation-framework/). API access alone is not authorization to scan.
